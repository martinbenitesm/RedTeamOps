# Acerca de
Meow es una máquina Linux muy fácil que guía a los jugadores en la configuración de sus máquinas de ataque, la conexión a los laboratorios de HTB mediante VPN y 
demuestra la estrategia para completarlos. La máquina se centra en técnicas de enumeración para principiantes y muestra la explotación de un servicio Telnet vulnerable mediante credenciales predeterminadas.
* Very Easy
* Linux

# Preguntas

## Tarea 01

**En ciberseguridad, los entornos aislados —como Pwnbox o las máquinas objetivo vulnerables— suelen ser VM. ¿Qué significa VM?**

**Respuesta:** `Virtual Machine`

## Tarea 02

**¿Qué herramienta usamos para interactuar con el sistema operativo y emitir comandos a través de la línea de comandos, como el que sirve para iniciar nuestra conexión VPN? También se conoce como consola o shell.**

**Respuesta:** `terminal`

## Tarea 03

**¿Qué servicio usamos para formar nuestra conexión VPN hacia los laboratorios de HTB?**

**Respuesta:** `openvpn`

## Tarea 04

**¿Qué herramienta usamos para probar nuestra conexión al objetivo con una solicitud de eco ICMP?**

**Respuesta:** `ping`

## Tarea 05

**¿Cuál es el nombre de la herramienta más común para encontrar puertos abiertos en un objetivo?**

**Respuesta:** `nmap`
